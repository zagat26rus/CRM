# Форма создания заявки

При пересборке фронта из исходников на сервере вернулась старая форма:
- блоки «Состояние устройства» и «Пожелания клиента» (их уже убирали в вашей сборке);
- выпадающие списки брендов/моделей были на нативном `datalist` и почти не видны.

Что сделано:
- `ComboInput.tsx` — поисковый выпадающий список в стиле Select CRM;
- из создания заявки убраны блоки состояния устройства и пожеланий;
- добавлен явный выбор «Тип запчасти»: Оригинал / Копия;
- подтягиваются бренды, модели и неисправности из каталога.

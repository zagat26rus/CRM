# Фикс создания заявки (статус)

Проблема: в форме «Новый заказ» статус по умолчанию был `Новый`, а в настройках компании статусы начинаются с `Создана`.
Поле статуса показывало «Выберите...» — заявка выглядела «непонятной».

Правки в `pages/Orders.tsx` и `pages/Documentation.tsx`:
- дефолт статуса `Создана`;
- если текущего статуса нет в списке компании — подставляется первый из списка;
- кнопка/заголовок: «Создать заявку» / «Новая заявка»;
- счётчик «Новые» учитывает `Создана` и `Принята`.

# FixNet CRM — production source

Репозиторий синхронизирован с исходниками, которые реально работают на `fedfix.ru`.

## Единственный источник кода
- `src/` — текущий frontend из `/var/www/black-crm/front/src`.
- `backend/src/` — текущий backend из `/var/www/black-crm/back/src`.
- `crm-backend-patches/` — архив старых backend-патчей, не источник для деплоя.

Форма заявки, квитанция и остальные экраны изменяются только в `src/`. Старые `frontend-restore`
удалены, чтобы они больше не могли вернуть устаревший интерфейс.

## Стек
- React 18 + TypeScript + Vite
- TailwindCSS (dark theme: black/yellow)
- React Router
- Zustand (простые уведомления)

## Как запустить локально
```bash
# 1) Установите Node.js 22+
# 2) Распакуйте архив и перейдите в папку
npm i
npm run dev

# Откройте: http://localhost:5173
```
> Если порт занят — измените `server.port` в `vite.config.ts`.

## Что реализовано
- Левое меню и верхняя панель, как на скринах.
- Страницы: Тренды (дашборд), Задачи, Заказы, Платежи, Клиенты, Маркетинг,
  Услуги, Склад, Магазин, Отчёты, Объявления, Настройки, Помощь.
- **Заказы**: таблица + модальное окно «Заказ» (с полями как на скрине).
  При сохранении — тост «Заявка оформлена, ожидайте звонка менеджера» и добавление строки в таблицу.
- **Платежи**: баланс + модалки «Приход» и «Расход» с методами оплаты и полями (как на скринах).
- **Тренды**: карточки + простые бары по дням/статусам.
- **Настройки**: плитки разделов.
- Базовые компоненты: `Modal`, `Field/Input/Select/Textarea`, `Toasts`.

## Правило следующих изменений
- Перед правкой сверять рабочий файл с production.
- Загружать только файлы текущей задачи.
- Не заменять `Orders.tsx` или `repairReceiptTemplate.ts` при изменениях, которые их не касаются.
- Никогда не разворачивать backup/restore-файлы поверх production.

Удачи с FixNet! 🚀


## Переменные окружения фронта
Создай `.env` в корне и укажи адрес API:
```
VITE_API_URL=http://localhost:5000/api
```

Backend запускается отдельно:
```bash
cd backend
npm install
npm start
```

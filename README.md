# FixNet CRM — Frontend (demo)

Жёлто‑чёрная CRM под ремонт техники. Это чистый **frontend** с мок‑данными,
созданный под локальный просмотр UI. Бэк здесь не нужен.

## Стек
- React 18 + TypeScript + Vite
- TailwindCSS (dark theme: black/yellow)
- React Router
- Zustand (простые уведомления)

## Как запустить локально
```bash
# 1) Установите Node.js 18+
# 2) Распакуйте архив и перейдите в папку
npm i
npm run dev

# Откройте: http://localhost:5173
```
> Если порт занят — измените `server.port` в `vite.config.ts`.

## Что реализовано
- Левое меню и верхняя панель, как на скринах.
- Страницы: Тренды (дашборд), Задачи, Заказы, Платежи, Клиенты, Маркетинг,
  Услуги, Склад, Магазин, Отчёты, Объявления, Настройки, Помощь.
- **Заказы**: таблица + модальное окно «Заказ» (с полями как на скрине).
  При сохранении — тост «Заявка оформлена, ожидайте звонка менеджера» и добавление строки в таблицу.
- **Платежи**: баланс + модалки «Приход» и «Расход» с методами оплаты и полями (как на скринах).
- **Тренды**: карточки + простые бары по дням/статусам.
- **Настройки**: плитки разделов.
- Базовые компоненты: `Modal`, `Field/Input/Select/Textarea`, `Toasts`.

## Как дальше наращивать
- Подключить реальный API (REST/GraphQL) к формам заказов/платежей.
- Вынести таблицы в общий компонент, прикрутить пагинацию/фильтры/экспорт.
- Добавить роли и авторизацию.
- Схемы валидации (zod/yup) + формы (react-hook-form).
- Компоненты статусов (цветные бейджи: в работе/готов/закрыт).
- Импорт клиентов из CSV, поиск по базе, карточку клиента.

Удачи с FixNet! 🚀


## Переменные окружения фронта
Создай `.env` в корне и укажи адрес API:
```
VITE_API_URL=http://localhost:4001
```
